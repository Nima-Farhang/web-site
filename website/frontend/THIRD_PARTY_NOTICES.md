# CSS attribution

`src/styles/reference-bootstrap.css` is adapted from [Nima-Farhang/Full-Stack-WebApp-Demo/frontend/src/bootstrap.min.css](https://github.com/Nima-Farhang/Full-Stack-WebApp-Demo/blob/master/frontend/src/bootstrap.min.css), retrieved 2026-11-10. It identifies itself as Bootswatch Lux 5.2.0 based on Bootstrap 5.2.0.

The original license headers are retained. Local adaptations remove the remote Google Fonts import and fix the source's invalid `var(bs-blu)` reference to `var(--bs-blue)`. The palette and system-font fallback are preserved; the portfolio layout and overrides live separately in `site.css`. No Bootstrap JavaScript is included.
